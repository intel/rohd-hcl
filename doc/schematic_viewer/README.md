# ROHD-HCL schematic viewer

This web-only Flutter application loads a ROHD netlist selected with the
`json` query parameter and renders it with `package:rohd_schematic_viewer`.

For example:

```text
schematic_viewer/index.html?json=../schematics/Component.rohd.json
```

CI builds the application with
`tool/gh_actions/build_schematic_viewer.sh`. Component netlists and
backward-compatible API-documentation redirects are generated by
`tool/gh_actions/create_schematic_pages.sh`.

The checked-in manifest uses hosted ROHD packages, including
`rohd_schematic_viewer` 0.3.0. This standalone application resolves its
dependencies separately from the root workspace; any local
`pubspec_overrides.yaml` here takes precedence over its hosted dependencies.
