rohd_hcl

ROHD Hardware Component Library

A hardware component library developed with ROHD. This library aims to collect a set of reusable, configurable components t//hat can be leveraged in other designs. These components are also intended as good examples of ROHD hardware implementations.

Check out the generator web app, which lets you explore some of the available components, configure them, and generate SystemVerilog.

The public library can be compiled to WebAssembly. A browser smoke test covers component simulation, typed interfaces, and SystemVerilog generation:

dart test -p chrome -c dart2wasm test/wasm_compatibility_test.dart

Individual APIs and tests that require native tools or file access may still require the Dart VM.

This project is always improving and growing! In a given category, initial components are primarily focused on correctness with room for optimization from there. Please feel free to contribute or provide feedback. Check out CONTRIBUTING for details on how to contribute.

This project is not intended to be the only place for reusable hardware components developed in ROHD. It's not even intended to be the only library. Contributions are welcomed to this library, but developers are also welcome to build independent packages or libraries, even if they may overlap.

Guidelines for Components

  • All hardware components should be Modules so that they are convertible to SystemVerilog
  • Components should be general and easily reusable
  • Components should be as configurable as may be useful
  • Components must be extensively tested
  • Components must have excellent documentation and examples
  • The first component in a category should be the simplest
  • Focus on breadth of component types before depth in one type
  • Add extensions to other classes to make component usage easier, when appropriate

Component List

The library is organized into the same component families used by the configurator. Examples include:

  • Arithmetic: adders, multipliers, counters, and floating-point operations.
  • Binary Math: binary transforms, finite fields, recurrences, and PRBS.
  • Bit Operations: searching, population counts, multiplexers, and shifting.
  • Clocking: clock gating, event detection, and clock-domain crossing.
  • Dataflow: sorting, selection, reduction, and serialization.
  • Encodings: Gray code, one-hot encoding, and priority encoders.
  • Error Control: error correction and parity.
  • Flow Control: arbiters, FIFOs, and ready/valid queues.
  • Inference: fixed-point attention, tensor movement, storage, and layout, with a runnable attention engine example.
  • Interfaces: AMBA and SPI interfaces and endpoints.
  • Memory: register files, associative memories, shift registers, and CSRs.
  • Models: memory models and protocol bus functional models.

The component list describes the source layout, links to component documentation, and includes ideas for future development. The configurator offers a subset of the library's components.
