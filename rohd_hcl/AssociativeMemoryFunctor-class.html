AssociativeMemoryFunctor

AssociativeMemoryFunctor class

A callable implementation for raw associative memory.

Calling the functor requires an exact semantic and timing match. Consumers that can adapt to an implementation-selected contract should call resolve and compose around the returned binding before invoking AssociativeMemoryBinding.instantiate.
