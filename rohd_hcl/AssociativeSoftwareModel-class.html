AssociativeSoftwareModel

AssociativeSoftwareModel class

Clock-stepped software model for indexed CAM updates and associative lookup.

Each call to step samples one request per port. An update with latency zero commits on that step; a lookup with latency zero completes on that step. Longer latencies are measured in subsequent calls to step. Lookup visibility is relative to updates committing on the same step.

This API uses null for a disabled request, rather than modeling uncertain enables or indices. Keys, masks, and stored validity retain four-state values. Raw access and snapshots do not capture external callers.
