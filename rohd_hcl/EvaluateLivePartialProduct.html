Print out the partial product matrix. bitvector = true will print out a compact bitvector to the right. value = true will print out the value of each row as 'unsigned (signed)'.
representation({bool markDown = false, bool bitvector = false, bool value = true}) → String

Available on PartialProductGeneratorBase, provided by the EvaluateLivePartialProduct extension

Return a string representation of the partial product array. S = Sign bit positive polarity = 1 final value). s = Sign bit positive polarity = 0 final value). I = Sign bit negative polarity = 1 final value). i = Sign bit negative polarity = 0 (final value). bitvector == true will print out a compact final bitvector array. value == true will print out the numerical value of the bitvector as 'unsigned (signed).
