FixedLatencyCoreGenerator

FixedLatencyCoreGenerator<Input extends Logic, Output extends Logic> typedef

FixedLatencyCoreGenerator<Input extends Logic, Output extends Logic> = Output Function({required Logic clk, required Input data, required Logic reset, required Logic start})

Builds an in-order fixed-latency core from wrapper-owned signals.

The returned payload must be produced exactly latency cycles after a start edge. The core must continue advancing through bubbles and must accept requests at the wrapper's configured initiation interval.
