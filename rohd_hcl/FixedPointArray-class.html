FixedPointArray

FixedPointArray class

A fixed-size collection of FixedPoint signals.

Arithmetic is applied elementwise and follows the same promotion rules as scalar FixedPoint operations. This collection intentionally uses a Dart list of independent signals; use a ROHD LogicArray when hardware-indexed packed or unpacked storage is required.
