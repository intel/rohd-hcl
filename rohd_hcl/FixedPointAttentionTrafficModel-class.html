FixedPointAttentionTrafficModel

FixedPointAttentionTrafficModel class

Static numeric-traffic model for one bounded fixed-point attention request.

The register-captured architecture transfers the complete query, key, and value tensors with its command. The scratchpad-backed architecture transfers only the query with the command and reads one independently packed key and value row per sequence position.
