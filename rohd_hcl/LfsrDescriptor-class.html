LfsrDescriptor

LfsrDescriptor class

Describes a right-shifting Fibonacci linear-feedback shift register.

For a degree-n polynomial, state bit zero is shifted out first. The new state bit n - 1 is the XOR of state bits selected by the polynomial's coefficients below x^n. For example, x^4 + x + 1 advances:

nextState[2:0] = state[3:1]
nextState[3]   = state[1] XOR state[0]

The polynomial must have positive degree. The default constructor also requires a non-zero constant coefficient. Primitivity is not required.
