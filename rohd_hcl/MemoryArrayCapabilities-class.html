MemoryArrayCapabilities

MemoryArrayCapabilities class

Fixed-timing capabilities of one memory array implementation.

The port limits describe the ports that can be instantiated. The total concurrent-access limit also describes any shared physical-port constraint. With raw DataPortInterface ports, the caller must enforce that limit.
