MemoryStorageState

MemoryStorageState class

Raw state adapter for existing storage without changing its legacy API.

Addresses are storage words. This bypasses address-alignment and invalid transaction callbacks; absent entries remain absent, distinct from stored X. It does not provide RAM timing or a behavioral SystemC memory engine.
