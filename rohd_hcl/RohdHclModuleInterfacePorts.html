RohdHclModuleInterfacePorts

RohdHclModuleInterfacePorts extension

Convenience methods for registering ROHD interfaces on HCL modules.

These methods are the HCL migration seam for alternate ROHD interface-port layouts. Module implementations should use them instead of calling connectIO or pairConnectIO directly.
