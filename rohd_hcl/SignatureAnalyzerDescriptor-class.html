SignatureAnalyzerDescriptor

SignatureAnalyzerDescriptor class

Describes a multiple-input signature analyzer.

Each input word is consumed bit zero first. For every input bit, the right-shifting recurrence in lfsrDescriptor advances once and the input bit is XORed into the newly inserted high state bit. The composed recurrence processes all inputWidth bits in one hardware cycle.
