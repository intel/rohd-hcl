StaticOrRuntimeIntKnob

StaticOrRuntimeIntKnob class

A GroupOfKnobs for an integer control that can be static or runtime.

Static configurations resolve to their integer value. Runtime configurations resolve to a StaticOrRuntimeControl that creates a named Logic input with the selected width.
